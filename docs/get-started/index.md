# Get started
Welcome! This section will help you get EMCPy installed and producing your first figure.
It’s designed for new users who want to get up and running quickly.

You’ll find:
- **Installation** — how to set up EMCPy in a clean environment.
- **Quickstart** — your very first plot with EMCPy.

```{toctree}
:maxdepth: 1
installation
quickstart
```

```{note}
We recommend working in a virtual environment (e.g., `venv` or `conda`) so EMCPy and its
dependencies don’t interfere with your system Python.
```
